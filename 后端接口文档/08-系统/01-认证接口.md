# 01 · 认证接口

## 1. 页面/模块概述

| 项 | 内容 |
|----|------|
| 页面名称 | 登录（`/#/login`，standalone） |
| 核心功能 | 医护账号登录、令牌注销、当前用户信息、令牌续期、服务存活探针 |
| 涉及实体 | 用户（user）、访问令牌（personal_access_token，Sanctum） |
| 数据源 | 登录页 `src/pages/LoginPage.tsx`（演示级），账号体系对齐 `scenario.json` 顶层 `staff` |

对应路由（`routes/meta.ts`）：`/login`（医护账号登录，standalone）。当前前端登录为演示级——任意账号密码进入；正式实现遵循总则 §2.6：Laravel Sanctum Token，登录返回 `token`，除健康检查与登录外均需 `Authorization: Bearer {token}`。

> 权限维度 `roleView`（`doctor`/`director`）用于质控/SLA 数据集权限，定义见 [05-质控管理/01-质控管理接口](../../05-质控管理/01-质控管理接口.md) §6.5；本模块用户表落地该字段。

## 2. 数据模型定义

### 2.1 用户表 `users`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 登录账号 | username | String | 是 | 登录账号（对齐 `scenario.staff[].id`，如 `weiyuan-emergency-doctor`） |
| 姓名 | name | String | 是 | 显示姓名 |
| 密码 | password_hash | String | 是 | BCrypt 哈希 |
| 数据权限角色 | role_view | String | 是 | `doctor`/`director` |
| 职业 | profession | String | 否 | doctor/nurse |
| 成员 | member_id | String | 否 | 关联 `organization_members.member_id`（医护档案） |
| 机构/科室 | institution_id / department_id | String | 否 | 关联 `organizations.org_id` / `departments.dept_id` |
| 电话 | phone | String | 否 | 联系电话 |
| 状态 | status | TINYINT | 是 | 1 启用 / 0 停用 |
| 最后登录 | last_login_at | DateTime | 否 | 最近一次登录时间 |

```sql
CREATE TABLE `users` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `username` VARCHAR(64) NOT NULL COMMENT '登录账号（对齐 staff.id）',
  `name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '显示姓名',
  `password_hash` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '密码哈希（BCrypt）',
  `role_view` VARCHAR(16) NOT NULL DEFAULT 'doctor' COMMENT '数据权限角色：doctor/director',
  `profession` VARCHAR(16) NOT NULL DEFAULT '' COMMENT '职业：doctor/nurse',
  `member_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '关联 organization_members.member_id',
  `institution_id` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '所属机构编码',
  `department_id` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '所属科室编码',
  `phone` VARCHAR(24) NOT NULL DEFAULT '' COMMENT '联系电话',
  `status` TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '状态：1启用0停用',
  `last_login_at` DATETIME NULL DEFAULT NULL COMMENT '最近登录时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted_at` DATETIME NULL DEFAULT NULL COMMENT '软删除时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`),
  KEY `idx_member` (`member_id`),
  KEY `idx_org_dept` (`institution_id`, `department_id`),
  KEY `idx_role` (`role_view`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='医护登录账号表';
```

索引说明：`uk_username` 保证账号唯一、支撑登录检索；`idx_member` 与医护档案（`organization_members`）打通；`idx_org_dept` 支撑按机构科室批量授权；`idx_role` 支撑 `roleView` 数据权限过滤。

### 2.2 访问令牌表 `personal_access_tokens`（Laravel Sanctum 内置）

由 `composer require laravel/sanctum` + `php artisan sanctum:install` 生成，无需手写。关键列：`id`、`tokenable_type`（`App\Models\User`）、`tokenable_id`、`name`、`token`（哈希）、`abilities`、`last_used_at`、`expires_at`。

> `refresh-token` 复用同一张令牌表：旧令牌注销后签发票名 `refresh` 的令牌，或利用 `abilities` 区分访问/刷新令牌；实现细节见 §3.5。

## 3. 接口清单

### 3.1 健康检查

| 项目 | 内容 |
|------|------|
| 接口名称 | 健康检查 ★ |
| 请求方法 | GET |
| 请求路径 | `/api/v1/health` |
| 接口描述 | 服务存活探针：返回服务状态、版本与当前时间；**无需鉴权** |
| 前端调用时机 | 应用启动、网关/负载均衡存活探测 |
| 前端渲染对应 | 启动状态提示 / 运维监控面板 |

**Query 参数：** 无。

**请求示例：**

```http
GET /api/v1/health HTTP/1.1
```

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "status": "up",
    "service": "huaxi-command-center-api",
    "version": "1.1.0",
    "time": "2026-10-13T09:00:00+08:00",
    "uptime": 864000
  }
}
```

**错误码：** 200；服务异常时返回 503（`code=503`，`message` 说明组件故障）。

---

### 3.2 登录

| 项目 | 内容 |
|------|------|
| 接口名称 | 登录 |
| 请求方法 | POST |
| 请求路径 | `/api/v1/auth/login` |
| 接口描述 | 医护账号 + 密码校验，成功返回 Sanctum Bearer Token 与用户概要 |
| 前端调用时机 | 登录页「进入系统」时 |
| 前端渲染对应 | 登录态保存、跳转首页 |
| 说明 | 前端演示级「任意输入进入」；正式实现须校验 `Hash::check`，失败返回 401 |

**Body 参数：**

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| username | String | 是 | 登录账号 | weiyuan-emergency-doctor |
| password | String | 是 | 密码 | ******** |
| device | String | 否 | 登录设备标记（令牌 name） | web |

**请求示例：**

```http
POST /api/v1/auth/login HTTP/1.1
Content-Type: application/json

{
  "username": "weiyuan-emergency-doctor",
  "password": "********",
  "device": "web"
}
```

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789",
    "tokenType": "Bearer",
    "expiresAt": "2026-10-14T09:00:00+08:00",
    "user": {
      "id": 1,
      "username": "weiyuan-emergency-doctor",
      "name": "陈明（演示）",
      "roleView": "doctor",
      "profession": "doctor",
      "institutionId": "weiyuan",
      "departmentId": "emergency"
    }
  }
}
```

**错误码：**

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数校验失败（username/password 为空） |
| 401 | 账号不存在或密码错误 |
| 403 | 账号已停用（status=0） |

### 3.3 登出

| 项目 | 内容 |
|------|------|
| 接口名称 | 登出 |
| 请求方法 | POST |
| 请求路径 | `/api/v1/auth/logout` |
| 接口描述 | 注销当前 Bearer Token（当前访问令牌作废） |
| 前端调用时机 | 用户点击「退出登录」 |
| 前端渲染对应 | 清理本地登录态、回登录页 |

**Body 参数：** 无。

**请求示例：**

```http
POST /api/v1/auth/logout HTTP/1.1
Authorization: Bearer {token}
```

**响应示例（成功）：**

```json
{ "code": 200, "message": "success", "data": null }
```

**错误码：** 200 / 401（Token 无效或已注销）。

---

### 3.4 当前用户

| 项目 | 内容 |
|------|------|
| 接口名称 | 当前用户 |
| 请求方法 | GET |
| 请求路径 | `/api/v1/auth/me` |
| 接口描述 | 返回当前登录用户信息与权限角色（`roleView`） |
| 前端调用时机 | 应用初始化、路由守卫校验登录态与角色 |
| 前端渲染对应 | 顶栏当前用户、菜单按角色显隐 |

**Body 参数：** 无。

**请求示例：**

```http
GET /api/v1/auth/me HTTP/1.1
Authorization: Bearer {token}
```

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "user": {
      "id": 1,
      "username": "weiyuan-emergency-doctor",
      "name": "陈明（演示）",
      "phone": "138****0101",
      "profession": "doctor",
      "institutionId": "weiyuan",
      "institutionName": "威远县人民医院",
      "departmentId": "emergency",
      "departmentName": "急诊科",
      "workAreas": ["reception", "ward"]
    },
    "roleView": "doctor",
    "permissions": ["patient.view", "consult.join", "transfer.accept"]
  }
}
```

**字段映射：**

| 前端展示 | 后端字段 | 类型 | 说明 |
|---------|---------|------|------|
| 当前用户 | user | Object | `users` 关联机构/科室后的完整概要 |
| 数据权限角色 | roleView | String | `doctor`/`director` |
| 权限项 | permissions[] | Array | 按角色/机构汇总的权限键 |
| 工作区 | workAreas[] | Array | 信接 `organization_members.work_areas`（reception/ward/field/ambulance） |

**错误码：** 200 / 401。

### 3.5 刷新令牌

| 项目 | 内容 |
|------|------|
| 接口名称 | 刷新令牌 |
| 请求方法 | POST |
| 请求路径 | `/api/v1/auth/refresh-token` |
| 接口描述 | 在访问令牌临近过期时续期：签发新令牌并注销旧令牌 |
| 前端调用时机 | 收到 401（令牌过期）后自动续期重试 |
| 前端渲染对应 | 无感知续期 |
| 说明 | 需携带当前有效 `Bearer` 令牌；结合总则 §2.6 仅健康检查与登录免鉴权 |

**Body 参数：**

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| device | String | 否 | 新令牌名 | web |

**请求示例：**

```http
POST /api/v1/auth/refresh-token HTTP/1.1
Authorization: Bearer {token}
Content-Type: application/json

{ "device": "web" }
```

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "1|zYxWvUtSrQpOnMlKjIhGfEdCbA9876543210",
    "tokenType": "Bearer",
    "expiresAt": "2026-10-14T09:00:00+08:00"
  }
}
```

**错误码：**

| code | 含义 |
|------|------|
| 200 | 成功 |
| 401 | 令牌无效、已注销或已过期 |

## 5. 交互与边界说明

- **鉴权范围**：健康检查（§3.1）与登录（§3.2）免鉴权；其余接口（含 `/auth/me`、`/auth/logout`、`/auth/refresh-token` 与全部业务接口）需 `Authorization: Bearer {token}`。
- **令牌生命周期**：`expires_at` 到期后令牌失效；前端在 401 且 `message` 为令牌过期时调用 `refresh-token` 续期，失败则跳登录页。
- **演示登录兼容**：MVP 前端为任意输入进入；后端联调期可对演示环境放行（任意账号签发 doctor 演示账号），正式环境严格 `Hash::check`。文档示例以 `weiyuan-emergency-doctor` 为准。
- **角色与机构权限**：`/auth/me` 返回的 `permissions` 由 `roleView` + `institutionId` 汇总（复用 `organization_permissions` 的 `perm_key`/`scope`），用于前端菜单与数据范围控制。
- **登出语义**：登出仅注销当前令牌；如需「全部设备下线」可另行扩展（本接口不覆盖）。

---

## 6. 前端对接注意事项

- **令牌存储**：将登录返回的 `token` 存于内存/本地，请求头统一 `Authorization: Bearer {token}`。
- **登录态恢复**：应用启动先调 `/auth/me` 恢复会话；401 则清理本地态跳转 `/#/login`。
- **错误提示**：登录 401 提示「账号或密码错误」；403 提示「账号已停用，请联系管理员」。
- **续期策略**：在令牌过期前（如剩余 ≤ 5 分钟）主动续期，避免请求中途失败。
