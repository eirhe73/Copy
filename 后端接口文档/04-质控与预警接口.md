# 04 · 质控与预警接口

## 1. 页面/模块概述

| 项 | 内容 |
|----|------|
| 页面名称 | 质控整改看板、质控标准、预警中心、床-患-设备绑定、基层转诊演示链 |
| 核心功能 | 质控标准与合规率、SLA 时效、24h 预警趋势与处置闭环、床/患者/设备/摄像头四元绑定、基层转诊流程 |
| 涉及实体 | 质控标准（qc_standard）、质控抽检记录（qc_check_record）、SLA 规则（sla_rule）、SLA 记录（sla_record）、预警趋势（warning_trend）、预警闭环（warning_closed_loop）、四元绑定（care_binding） |
| 数据源 | `qc-standards.json`、`qc-sla.json`、`warning-demo.json`、`care-bindings.json`、`grassroots-demo.json` |

> 说明：上述 JSON 分别由主站占位页的增强脚本加载（如 `qc-sla-enhance.js`、`warning-demo-enhance.js`、`care-link-enhance.js`、`grassroots-demo-enhance.js`）。此外 `public/scenario.json`（228KB）为主站「一体化指挥中心」的**完整演示快照数据集**（内含全量 patients / vehicles / beds / 图表序列等虚构数据，`schemaVersion: 2`），作为演示种子数据使用，本文档不为其单独定义接口，正式环境由各业务域接口替代。

## 2. 数据模型定义

### 2.1 质控标准表 `qc_standards`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 标准编号 | standard_id | String | 是 | 如 QC-ER-001 |
| 标准名 | name | String | 是 | 如「120出车响应」 |
| 目标 | target | String | 是 | 达标要求描述 |
| 采样周期 | sample_period | String | 是 | 月/季/年 |
| 合规率 | compliance_rate | Decimal(5,4) | 是 | 0~1 |
| 版本 | version | String | 是 | 如 2026-Q4-v1 |

```sql
CREATE TABLE `qc_standards` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `standard_id` VARCHAR(32) NOT NULL COMMENT '标准编号，如 QC-ER-001',
  `name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '标准名称',
  `target` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '达标要求',
  `sample_period` VARCHAR(16) NOT NULL DEFAULT '月' COMMENT '采样周期',
  `compliance_rate` DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '合规率 0~1',
  `version` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '标准版本',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_standard_version` (`standard_id`, `version`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='质控标准表';
```

### 2.2 质控抽检记录表 `qc_check_records`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 抽检时间 | check_at | DateTime | 是 | 抽检时间 |
| 标准 | standard_id | String | 是 | 关联标准 |
| 是否达标 | ok | Boolean | 是 | 达标标记 |
| 备注 | note | String | 否 | 抽检说明 |

```sql
CREATE TABLE `qc_check_records` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `standard_id` VARCHAR(32) NOT NULL COMMENT '标准编号',
  `check_at` DATETIME NOT NULL COMMENT '抽检时间',
  `ok` TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否达标：0否1是',
  `note` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '抽检备注',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_standard_time` (`standard_id`, `check_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='质控抽检记录表';
```

### 2.3 SLA 规则表 `sla_rules` 与记录表 `sla_records`

```sql
CREATE TABLE `sla_rules` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `rule_id` VARCHAR(32) NOT NULL COMMENT '规则编号，如 SLA-ALERT',
  `name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '规则名，如 预警后到床',
  `limit_minutes` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '时限（分钟）',
  `audience` VARCHAR(128) NOT NULL DEFAULT '' COMMENT '数据受众说明',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_rule_id` (`rule_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='SLA时效规则表';

CREATE TABLE `sla_records` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `record_id` VARCHAR(64) NOT NULL COMMENT '记录编号，如 SLA-20261012-01',
  `kind` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '类型，如 预警到床/出警到院',
  `rule_id` VARCHAR(32) NOT NULL COMMENT '规则编号',
  `subject` VARCHAR(128) NOT NULL DEFAULT '' COMMENT '主体（患者/车辆）',
  `owner` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '责任人',
  `role_view` VARCHAR(16) NOT NULL DEFAULT 'doctor' COMMENT '数据权限角色：doctor/director',
  `started_at` DATETIME NOT NULL COMMENT '开始时间',
  `arrived_at` DATETIME NULL DEFAULT NULL COMMENT '到达时间',
  `limit_minutes` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '时限（分钟）',
  `used_minutes` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '已用（分钟）',
  `overtime` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否超时：0否1是',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_record_id` (`record_id`),
  KEY `idx_role_rule` (`role_view`, `rule_id`),
  KEY `idx_started` (`started_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='SLA时效记录表';
```

索引说明：`idx_role_rule` 支撑「当班医生看自己 / 管理者看全院」的数据权限过滤；`idx_started` 支撑时间范围查询。

### 2.4 预警趋势表 `warning_trends` 与闭环表 `warning_closed_loop`

```sql
CREATE TABLE `warning_trends` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `trend_id` VARCHAR(32) NOT NULL COMMENT '趋势编号，如 TR-01',
  `patient_label` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者标签，如 心内科 12床',
  `metric` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '指标，如 NEWS/SpO₂/心率',
  `current_value` DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT '当前值',
  `predicted_value` DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT '预测值',
  `within_minutes` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '预测分钟',
  `note` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '说明',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_trend_id` (`trend_id`)

CREATE TABLE `warning_closed_loop` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',

  `stat_date` DATE NOT NULL COMMENT '统计日期',

  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_stage_date` (`stage`, `stat_date`)

```

## 5. 交互与边界说明

- **数据权限**：SLA 记录按 `roleView` 过滤——`doctor` 仅返回本人（`owner`）记录，`director` 返回全部；前端根据登录角色传参。
- **预警闭环**：四个阶段计数按 `stat_date` 聚合，逐级递减形成漏斗；`closedLoopPercent` 由「干预完成 ÷ 预警触发」计算。
- **质控版本**：`qc_standards` 支持多版本并存，接口默认返回最新版本。
- **绑定关系**：床/患/设备/摄像头为四元绑定，`care_bindings` 与 `medical_devices` 数据需保持一致性。

## 6. 前端对接注意事项

- **生命周期**：预警/质控看板建议轮询（5~15s），由增强脚本处理。
- **loading**：KPI 与趋势数据未返回时显示占位骨架。
- **错误提示**：无权限（403）时提示「无权限查看该数据」。
- **空数据**：无预警时趋势列表为空、闭环漏斗为 0；无绑定关系时列表为空。
