## 1. 板块概述

| 项 | 说明 |
|----|------|
| 业务边界 | 院前 120 从接警、出车、车上登记到远程会诊发起、车辆定位监控的全链路 |
| 主前端入口 | `dispatch.html`（Vue 四页 + 车辆监控 Tab） |
| 辅入口 | 主站 `/#/consultations`（远程会诊）、指挥中枢二级菜单经 `nav-ia-enhance.js` 跳转 |
| 基础路径 | `/api/v1` |
| 认证 | Laravel Sanctum，`Authorization: Bearer {token}`（见 [00-总览/README.md](../00-总览/README.md) §2.6） |
| 统一响应 | `{ "code": 200, "message": "success", "data": {} }` |

### 1.1 子模块与入口对照

| 编号 | 子模块 | 前端入口 | Mock / 实现状态 |
|------|--------|----------|-----------------|
| 1.1 | 急救事件 | `dispatch.html#events` | 真实 · `dispatch-live.json` |
| 1.2 | 实时出警 | `dispatch.html#live` | 真实 · 同上，10s 轮询 |
| 1.3 | 远程会诊 | `/#/consultations`、`/#/room/:token` | 真实 · `consultation-admission.json` 等 |
| 1.4 | 患者登记 | `dispatch.html#register`、`#live` 就地登记 | 真实 · 提交演示存本地 |
| 1.5 | 车辆监控 | `dispatch.html#monitor`（或 `#live` 内嵌地图） | 真实 · `vehicles-gps.json`，5s 轮询 |

### 1.2 核心实体

| 实体 | 表名 | 说明 |
|------|------|------|
| 急救事件 | `emergency_events` | 一次出车一条事件 |
| 救护车 | `vehicles` | 车辆台账、班组、当前任务 |
| 车辆位置 | `vehicle_locations` | GPS、ETA、轨迹 |
| 急救患者登记 | `emergency_patients` | 车上就地登记 |
| 会诊会话 | `consult_sessions` | 院前/入院远程会诊 |

## 2. 子模块接口

### 2.1 · 1.1 急救事件

**功能说明：** 以 120 任务为粒度展示历史与进行中事件，支持查看详情、跳转出警处理与登记。

| 前端 | 说明 |
|------|------|
| 页面 | `dispatch.html#events`（EventsList.vue） |
| 轮询 | 与实时出警共用列表接口，事件页加载时拉取 |

| # | 方法 | 路径 | 接口名称 | 说明 |
|---|------|------|----------|------|
| 1 | GET | `/api/v1/dispatch/events` | 急救事件列表 | 列表 + `activeCount`；支持 `status` 过滤 |
| 2 | GET | `/api/v1/dispatch/events/{eventId}` | 事件详情 | 含 `scorePlan`、`treatPlan` |
| 3 | POST | `/api/v1/dispatch/events` | 创建急救事件 | 接警建档，初始「等候分派」 |
| 4 | PUT | `/api/v1/dispatch/events/{eventId}` | 更新事件状态 | 出警中 → 现场处置 → 返院途中 |
| 5 | POST | `/api/v1/dispatch/tasks` | 任务分派 | 指派车辆与随车班组 |

**主要 Query（列表）：** `status`（逗号分隔英文码）、`pageNum`、`pageSize`。

**状态枚举：** `DISPATCHING` 出警中 · `ON_SCENE` 现场处置 · `RETURNING` 返院途中（车辆另有 `STANDBY` 待命）。

**详述文档：** [01-指挥大屏/02-院前急救调度接口.md](../01-指挥大屏/02-院前急救调度接口.md) §2.3、§3.1～3.7。

### 2.2 · 1.2 实时出警

**功能说明：** 今日出警看板：左侧事件卡片，选中后右侧车辆看板 + 就地登记表单；展示评分/救治方案。

| 前端 | 说明 |
|------|------|
| 页面 | `dispatch.html#live`（LiveDispatch.vue） |
| 轮询 | **10s** `GET /api/v1/dispatch/events`（进行中状态） |

| # | 方法 | 路径 | 接口名称 | 说明 |
|---|------|------|----------|------|
| 1 | GET | `/api/v1/dispatch/events` | 急救事件列表 | 与 1.1 共用；看板侧栏卡片 |
| 2 | GET | `/api/v1/dispatch/events/{eventId}` | 事件详情 | 选中卡片后加载看板 |
| 3 | GET | `/api/v1/ambulances/{id}` | 救护车详情 | 车辆看板班组与状态 |
| 4 | PUT | `/api/v1/dispatch/events/{eventId}` | 更新事件状态 | 看板内状态流转 |

**详述文档：** [02-院前急救调度接口.md](../01-指挥大屏/02-院前急救调度接口.md) §3.1、§3.2、§3.6、§3.8。

### 2.3 · 1.3 远程会诊

**功能说明：** 从出警/登记页带参发起会诊（`task`、`plate`、`vehicle`、`complaint`）；队列接诊、会诊室音视频与意见。

| 前端 | 说明 |
|------|------|
| 页面 | `/#/consultations`、`/#/room/:token`；出警页链：`/#/consultations?plate=…&vehicle=…` |
| 门户 | `meeting-portal.html#consult`（入院会诊演示） |

| # | 方法 | 路径 | 接口名称 | 说明 |
|---|------|------|----------|------|
| 1 | GET | `/api/v1/consultations` | 会诊队列 | 待接诊 / 进行中列表 |
| 2 | GET | `/api/v1/consultations/{id}` | 会诊详情 | 单场会诊 |
| 3 | POST | `/api/v1/consultations` | 发起会诊 | Body 可带 `task120Id`、车牌、主诉 |
| 4 | POST | `/api/v1/consultations/{id}/accept` | 接诊 | 指定接诊医生 |
| 5 | GET | `/api/v1/consultations/doctors` | 接诊医生列表 | 发起/分配时用 |
| 6 | GET | `/api/v1/consultations/admission` | 入院会诊会话 | 门户独立运行 + 120 兼容 |
| 7 | GET | `/api/v1/rooms/{token}` | 会诊室信息 | 入会前拉取 |
| 8 | GET | `/api/v1/rooms/{token}/materials` | 临床资料 | 会诊室资料区 |
| 9 | POST | `/api/v1/rooms/{token}/opinions` | 提交会诊意见 | 写回患者时间轴 |
| 10 | POST | `/api/v1/rooms/{token}/join` | 患者移动入会 | 手机端 |

**120 兼容约定：** 发起会诊时 URL 或 Body 携带 `task120Id` / `vehicleId` / `chiefComplaint`，后端回填患者与会话关联。

**详述文档：** [04-会诊协同/01-会诊协同接口.md](../04-会诊协同/01-会诊协同接口.md)。

### 2.4 · 1.4 患者登记

**功能说明：** 车上或独立页一屏录入；支持草稿与正式提交；可与事件、120 任务号、车辆绑定。

| 前端 | 说明 |
|------|------|
| 页面 | `dispatch.html#register`；`#live` 内 RegisterForm |
| 演示 | 草稿可存 `localStorage`（`huaxi-er-draft-*`） |

| # | 方法 | 路径 | 接口名称 | 说明 |
|---|------|------|----------|------|
| 1 | POST | `/api/v1/dispatch/patients` | 急救患者就地登记 | `isDraft=1` 草稿，`0` 正式提交 |
| 2 | POST | `/api/v1/patients` | 院内患者登记 | 主站 `/#/register`（非车上场景） |
| 3 | POST | `/api/v1/patients/ocr-id` | 证件识别 | 身份证 OCR 回填 |
| 4 | POST | `/api/v1/patients/pre-admission` | 院前上报 | 院前信息推送 HIS |

**Body 核心字段（就地登记）：** `eventId`、`task120Id`、`vehicleId`、`name`、`gender`、`age`、`phone`、`chiefComplaint`、`isDraft`。

**详述文档：** 车上登记 → [02-院前急救调度接口.md](../01-指挥大屏/02-院前急救调度接口.md) §2.4、§3.4；院内登记 → [03-患者与床位/02-患者管理接口.md](../03-患者与床位/02-患者管理接口.md)。

### 2.5 · 1.5 车辆监控

**功能说明：** 县域地图展示 120 车辆点位、状态、ETA；可选车内监控占位（演示未接流）。

| 前端 | 说明 |
|------|------|
| 页面 | `dispatch.html#monitor`（VehicleMonitor.vue） |
| 轮询 | **5s** GPS；GIS 大屏为 10s |

| # | 方法 | 路径 | 接口名称 | 说明 |
|---|------|------|----------|------|
| 1 | GET | `/api/v1/vehicles/gps` | 在途车辆 GPS 与 ETA | 散点 + 侧栏 ETA |
| 2 | GET | `/api/v1/ambulances` | 救护车列表 | 台账与当前事件 |
| 3 | GET | `/api/v1/transfers/{id}/track` | 轨迹回放 | 单车历史轨迹（转运详情页） |
| 4 | GET | `/api/v1/monitoring/streams` | 监控流列表 | 车内/远程 ICU 多路（正式环境） |
| 5 | GET | `/api/v1/monitoring/streams/{id}` | 单路监控拉流 | 车内画面 |

**响应要点（GPS）：** `vehicles[].lng/lat`、`status`、`etaMinutes`、`route`（可选折线）。

**详述文档：** GPS → [01-指挥大屏/00-GIS协同态势接口.md](../01-指挥大屏/00-GIS协同态势接口.md) §3.2；车辆台账 → [02-院前急救调度接口.md](../01-指挥大屏/02-院前急救调度接口.md) §3.3；视频监控 → [03-转运与视频监控接口.md](../01-指挥大屏/03-转运与视频监控接口.md)。

## 4. 联调与性能建议

| 项 | 建议 |
|----|------|
| 高频轮询 | `dispatch/events` 10s、`vehicles/gps` 5s；后端宜 3～5s 轻量缓存 |
| 索引 | `emergency_events(status, started_at)`、`vehicle_locations(vehicle_id, located_at)` |
| 权限 | 调度员：事件 CRUD + 分派；随车医生：登记 + 发起会诊；只读角色：列表/GPS |
