# 02 · 床患设备绑定接口

## 1. 模块概述

| 项 | 内容 |
|----|------|
| 页面名称 | 床位详情（`/#/bed/:id`）、患者详情（`/#/patient/:id`）中的绑定跳链 |
| 核心功能 | 床位 / 患者 / 设备 / 摄像头四元绑定关系查询，支撑跨对象互跳 |
| 涉及实体 | 四元绑定（care_binding） |
| 数据源 | `public/api/care-bindings.json` |

---

## 2. 数据模型定义

### 2.1 床-患-设备四元绑定表 `care_bindings`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 范围 | scope | String | 是 | 本院/协作医院/下级医院 |
| 医院 | hospital | String | 是 | 医院名称 |
| 病区 | ward | String | 是 | 病区/科室 |
| 床位 | bed_id / bed_label | String | 是 | 床位编号与标签 |
| 患者 | patient_id / patient_name | String | 是 | 患者编号与姓名 |
| 设备 | device_id / device_name | String | 否 | 设备编号与名称 |
| 摄像头 | camera_id | String | 否 | 摄像头编号 |
| 绑定时间 | bound_at | DateTime | 是 | 绑定时间 |

```sql
CREATE TABLE `care_bindings` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `scope` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '范围：0本院1协作医院2下级医院',
  `hospital` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '医院名称',
  `ward` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '病区/科室',
  `bed_id` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '床位编号',
  `bed_label` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '床位标签',
  `patient_id` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者编号',
  `patient_name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者姓名',
  `device_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '设备编号',
  `device_name` VARCHAR(32) NULL DEFAULT NULL COMMENT '设备名称',
  `camera_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '摄像头编号',
  `bound_at` DATETIME NOT NULL COMMENT '绑定时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_bed` (`bed_id`),
  KEY `idx_patient` (`patient_id`),
  KEY `idx_device` (`device_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='床患设备四元绑定表';
```

## 3. 接口清单

### 3.1 获取床-患-设备四元绑定

| 项目 | 内容 |
|------|------|
| 接口名称 | 获取床-患-设备四元绑定 |
| 请求方法 | GET |
| 请求路径 | `/api/v1/care-bindings` |
| 接口描述 | 返回本院/协作/下级医院的床位、患者、设备、摄像头绑定关系 |
| 前端调用时机 | 患者详情/床位页加载时 |
| 前端渲染对应 | 绑定关系跳链 |

**响应示例（成功）：**
