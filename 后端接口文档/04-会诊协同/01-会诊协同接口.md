# 01 · 会诊协同接口

## 1. 模块概述

| 项 | 内容 |
|----|------|
| 页面名称 | 远程会诊（`/#/consultations`）、会诊室（`/#/room/:token`）、会诊门户入院会诊（`meeting-portal.html#consult`） |
| 核心功能 | 会诊队列、发起会诊、接诊、会诊室（音视频/意见/资料）、入院会诊会话 |
| 涉及实体 | 会诊会话（consult_session）、会诊成员（consult_participant） |
| 数据源 | `public/api/consultation-admission.json` |

对应路由（`routes/meta.ts`）：`/consultations`（会诊队列、接诊医生、会诊链接）、`/room/:token`（音视频、会诊意见、临床资料）。

## 2. 数据模型定义

### 2.1 会诊会话表 `consult_sessions`

| 前端展示 | 数据库字段 | 类型 | 必填 | 示例 | 说明 |
|---------|-----------|------|------|------|------|
| 会话号 | session_id | String | 是 | `adm-2026-1001` | 会诊会话编号 |
| 模式 | mode | String | 是 | `standalone` | 运行模式 |
| 兼容120 | compatible120 | Boolean | 是 | `true` | 是否兼容 120 任务 |
| 患者姓名/性别/年龄 | patient_name / patient_gender / patient_age | - | 是 | 演示患者01 / 男 / 38 | 患者信息 |
| 主诉 | chief_complaint | String | 是 | `胸痛、出汗` | 主诉 |
| 120 任务号 | task120_id | String | 否 | `120-WY-88421` | 关联任务 |
| 医院/科室 | hospital / department | String | 是 | 威远县人民医院 / 急诊科 | 接诊科室 |
| 状态 | status | Integer | 是 | `0` | 0待接诊1会诊中2已结束 |

```sql
CREATE TABLE `consult_sessions` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `session_id` VARCHAR(64) NOT NULL COMMENT '会诊会话编号',
  `mode` VARCHAR(16) NOT NULL DEFAULT 'standalone' COMMENT '运行模式',
  `compatible120` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否兼容120任务：0否1是',
  `patient_name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者姓名',
  `patient_gender` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '性别：0男1女',
  `patient_age` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '年龄',
  `chief_complaint` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '主诉',
  `task120_id` VARCHAR(32) NULL DEFAULT NULL COMMENT '120 任务号',
  `hospital` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '医院',
  `department` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '科室',
  `status` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '状态：0待接诊1会诊中2已结束',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_session_id` (`session_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='会诊会话表';
```

### 2.2 会诊成员表 `consult_participants`

| 字段名 | 数据库字段 | 类型 | 必填 | 说明 |
|--------|-----------|------|------|------|
| 会话 | session_id | String | 是 | 关联会话 |
| 角色 | role | String | 是 | 院前医生 / 接诊专家 |
| 姓名 | name | String | 是 | 成员姓名 |
| 在线 | online | Boolean | 是 | 在线状态 |

```sql
CREATE TABLE `consult_participants` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `session_id` VARCHAR(64) NOT NULL COMMENT '会诊会话编号',
  `role` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '角色',
  `name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '成员姓名',
  `online` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '在线：0离线1在线',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_session` (`session_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='会诊成员表';
```

## 4. 会诊队列与会诊室数据模型（续）

> 会诊队列、发起会诊、接诊、会诊室、临床资料、会诊意见等接口（#69~#77）复用 §2.1 `consult_sessions`（会诊会话）与 §2.2 `consult_participants`（会诊成员）两表；其中「会诊链接 / 会诊码」以会诊室 token 作为会诊室主键标识，另新增以下 3 张表。
>
> 本节以下接口无独立 Mock JSON，字段依据会诊业务域 + `routes/meta.ts` 模块描述（会诊队列 / 接诊医生 / 会诊链接、音视频 / 会诊意见 / 临床资料、手机端入会 / 进度同步）+ `scenario.json` 数据推导，标注「**字段为规范设计**」。

### 4.1 会诊房间表 `consult_rooms`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 会诊室标识 | token | String | 是 | 会诊室唯一标识（UUID），作入会链接与主键标识 |
| 会诊码 | consult_code | String | 是 | token 前 6 位短码，用于展示 / 口令入会 |
| 会诊会话 | session_id | String | 是 | 关联 `consult_sessions.session_id` |
| 患者 | patient_id | String | 是 | 患者编号 |
| 房间名 | room_name | String | 是 | `{患者姓名} · {医院} · {科室}` 形式 |
| 音视频模式 | media_mode | String | 是 | `RTC` 正式 / `PLACEHOLDER` 占位 |
| RTC 地址 | rtc_url | String | 否 | 生产接第三方 RTC；演示为占位 |
| 状态 | status | Integer | 是 | 复用会诊状态 0待接诊1会诊中2已结束 |
| 开始 / 结束 | opened_at / closed_at | DateTime | 否 | 接诊后 / 提交意见后 |

```sql
CREATE TABLE `consult_rooms` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `token` VARCHAR(64) NOT NULL COMMENT '会诊室标识（UUID，作入会链接与主键标识）',
  `consult_code` CHAR(6) NOT NULL DEFAULT '' COMMENT '会诊码（token 前 6 位展示）',
  `session_id` VARCHAR(64) NOT NULL COMMENT '会诊会话编号，关联 consult_sessions.session_id',
  `patient_id` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者编号',
  `room_name` VARCHAR(128) NOT NULL DEFAULT '' COMMENT '会诊室名称',
  `media_mode` VARCHAR(16) NOT NULL DEFAULT 'PLACEHOLDER' COMMENT '音视频模式：RTC正式/PLACEHOLDER占位',
  `rtc_url` VARCHAR(255) NULL DEFAULT NULL COMMENT '音视频服务地址（生产接第三方 RTC）',
  `status` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '状态：0待接诊1会诊中2已结束',
  `opened_at` DATETIME NULL DEFAULT NULL COMMENT '会诊开始时间（接诊后）',
  `closed_at` DATETIME NULL DEFAULT NULL COMMENT '会诊结束时间（提交意见后）',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_token` (`token`),
  KEY `idx_session` (`session_id`),
  KEY `idx_patient` (`patient_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='会诊房间表';
```

索引说明：

- `uk_token`：token 作为会诊室唯一主键标识，支撑 `/room/{token}`、`/join/{token}` 按 token 直达。
- `idx_session` / `idx_patient`：会诊室 ↔ 会话 ↔ 患者关联查询。
- `idx_status`：按会诊状态筛选房间。

### 4.2 临床资料表 `consult_materials`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 会诊室 | room_token | String | 是 | 关联 `consult_rooms.token` |
| 会诊会话 | session_id | String | 是 | 关联会诊会话 |
| 患者 | patient_id | String | 是 | 患者编号 |
| 资料类型 | kind | String | 是 | 护理/检验/用药/评估/病程记录等 |
| 标题 | title | String | 是 | 资料标题 |
| 内容 | content | Text | 是 | 资料正文 |
| 来源 | source | String | 是 | local 本机 / his / emr / lis |
| 作者 | author_id / author_name | String | 是 | 作者账号与姓名 |
| 共享时间 | shared_at | DateTime | 是 | 共享入会诊室时间 |

```sql
CREATE TABLE `consult_materials` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `room_token` VARCHAR(64) NOT NULL COMMENT '会诊室 token',
  `session_id` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '会诊会话编号',
  `patient_id` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者编号',
  `kind` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '资料类型：护理记录/检验记录/用药记录/评估记录/病程记录',
  `title` VARCHAR(128) NOT NULL DEFAULT '' COMMENT '资料标题',
  `content` TEXT NOT NULL COMMENT '资料内容',
  `source` VARCHAR(16) NOT NULL DEFAULT 'local' COMMENT '来源：local本机演示/his/emr/lis',
  `author_id` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '作者账号',
  `author_name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '作者姓名',
  `shared_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '共享时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_room` (`room_token`),
  KEY `idx_session` (`session_id`),
  KEY `idx_patient` (`patient_id`),
  KEY `idx_kind` (`kind`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='会诊临床资料表';
```

索引说明：

- `idx_room` / `idx_session`：按会诊室 / 会话拉取共享资料（临床资料页按 token 全量加载）。
- `idx_patient`：患者跨会诊历史资料检索。
- `idx_kind`：按资料类型分组展示（护理 / 检验 / 用药 / 评估 / 病程）。

### 5.3 发起会诊

| 项目 | 内容 |
|------|------|
| 接口名称 | 发起会诊（创建会诊） |
| 请求方法 | POST |
| 请求路径 | `/api/v1/consultations` |
| 接口描述 | 创建一场会诊申请：绑定患者、目标科室与意向医生，生成会诊室 token，状态置为待接诊 |
| 前端调用时机 | 患者详情「发起远程会诊」、120/出警「发起远程会诊」按钮 |
| 前端渲染对应 | 发起成功提示（会诊链接已创建）、会诊队列新增条目 |

> 字段为规范设计；`token` 为前端预生成 UUID（`crypto.randomUUID()`），后端未传则服务端生成并回传。

**Body 参数：**

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| patientId | String | 否 | 已登记患者编号；未登记时以下患者字段必填 | DEMO-001 |
| patientName | String | 条件 | 患者姓名 | 王秀兰 |
| gender | String | 条件 | 性别 | MALE / FEMALE |
| age | Integer | 否 | 年龄 | 45 |
| chiefComplaint | String | 条件 | 主诉 | 胸痛、出汗 |
| sourceHospital | String | 否 | 发起医院 | 威远县人民医院 |
| sourceDepartment | String | 否 | 发起科室 | 急诊科 |
| targetHospital | String | 是 | 接诊医院 | 威远县人民医院 |
| targetDepartment | String | 是 | 接诊科室 | 急诊科 |
| nominatedDoctorId | String | 否 | 意向接诊医生（可空，接诊时可再指定） | weiyuan-emergency-doctor |
| token | String | 否 | 预生成会诊室 token（UUID） | c9f1a0e2-... |
| note | String | 否 | 备注 | 家属要求尽快 |

**请求示例：**

```http
POST /api/v1/consultations HTTP/1.1
Authorization: Bearer {token}
Content-Type: application/json

{
  "patientId": "DEMO-001",
  "targetHospital": "威远县人民医院",
  "targetDepartment": "急诊科",
  "nominatedDoctorId": "weiyuan-emergency-doctor",
  "token": "c9f1a0e2-4b7d-4a3c-9f01-2e5d7b8a6c1e"
}
```

**响应示例（成功）：**


## 6. 状态与枚举值

### 6.1 会诊状态 `status`

复用 [README](../00-总览/README.md) §3.5 会诊会话状态枚举：

| code（存储） | 常量 | label（显示） | 说明 |
|-------------|------|--------------|------|
| 0 | `WAITING` | 待接诊 | 已发起，待接诊科室领取 |
| 1 | `IN_CALL` | 会诊中 | 已接诊，进入会诊室 |
| 2 | `FINISHED` | 已结束 | 会诊意见已提交 |

状态流转：`WAITING → IN_CALL → FINISHED`（发起会诊 → 接诊 → 提交会诊意见）。

### 6.2 会诊意见执行反馈 `feedback.value`

| 存储值 | 显示文本 |
|--------|---------|
| `已收到` | 已收到 |
| `已执行` | 已执行 |
| `情况有变化` | 情况有变化 |
| `请求再次联系` | 请求再次联系 |

### 6.3 临床资料类型 `kind` 与来源 `source`

- 类型 `kind`：`护理记录` / `检验记录` / `用药记录` / `评估记录` / `病程记录`。
- 来源 `source`：`local`（本机演示记录）/ `his` / `emr` / `lis`（外部系统，未接入则标记为 local）。

### 6.4 音视频模式 `media_mode`

| 存储值 | 显示文本 | 说明 |
|--------|---------|------|
| `PLACEHOLDER` | 演示占位 | 演示环境，音视频为占位，非商用 RTC |
| `RTC` | 正式 | 生产接第三方 RTC / 跨网络多方会诊 |

## 7. 交互与边界说明

- **会诊链接与会诊码**：每次发起会诊生成唯一 `token`（UUID），`consultCode` 取 token 前 6 位用于展示 / 口令入会；`/#/room/{token}` 为参会入口，`/#/join/{token}` 为患者手机端入会入口，二者均按 token 直达，后端须保证 `uk_token` 唯一。
- **状态流转唯一方向**：仅 `WAITING → IN_CALL → FINISHED`；「未接诊」时不可提交意见，「已接诊」不可重复接诊，「已结束」不可再次提交。
- **权限边界**：接诊仅目标科室医生或管理员；提交意见仅本次接诊医生（`acceptedBy`）或管理员；临床资料跨机构查看需授权（授权范围内）。
- **同一患者互斥**：同一患者仅允许存在一场「待接诊或会诊中」的申请，避免并发重复建会诊（HTTP 409）。
- **120 / 出警带入**：从出警、患者登记页点击「发起远程会诊」会通过 URL query 携带 `task`（120 任务号）、`plate`（车牌）、`vehicle`（车辆编号）、`complaint`（主诉），后端应支持以 `task120Id` 回填会诊患者信息（参考 §3.1 `task120Id` 字段）。
- **音视频占位**：演示环境音视频为占位，不影响会诊文字流程（意见 / 资料 / 反馈照常流转）。

## 8. 前端对接注意事项

- **队列轮询**：`/#/consultations` 页加载即拉取待接诊队列，建议 10s 轮询（演示为本地 state，未真实轮询）。
- **接诊按钮态**：管理员须先在下拉「指定具体医生」选定后再接诊；医生本人直接「由我接诊」。
- **入会链接复制**：复制会诊链接失败时前端回退提示「浏览器不允许复制，请从会诊记录选取链接」；短信发送为「短信待接入」占位。
- **空状态**：无待接诊申请时显示「暂无待接诊申请」；临床资料为空时提示「暂无授权范围内的临床资料」。
- **错误提示**：会诊意见为空提示「会诊意见不能为空」；重复接诊提示「该会诊已被接诊，不能重复领取」；重复建档提示「已有待接诊或进行中的会诊」。
