# 03 · 会诊门户与床位设备接口

## 1. 页面/模块概述

| 项 | 内容 |
|----|------|
| 页面名称 | 会诊门户（`meeting-portal.html`，九项交付） |
| 核心功能 | 科室床位监控、床旁设备动态绑定、入院远程会诊、医生快速登记 |
| 涉及实体 | 科室床位（department_bed）、医疗设备（medical_device）、会诊会话（consult_session）、会诊成员（consult_participant） |
| 数据源 | `public/api/beds-by-dept.json`、`public/api/device-bindings.json`、`public/api/consultation-admission.json` |

前端页面（Hash 路由见 [App.vue](../huaxi-command-center/src/meeting/App.vue)）：`#beds` 床位监控、`#devices` 设备绑定、`#consult` 入院会诊、`#register` 医生登记；`#layout`/`#checklist`/`#video` 为静态页无接口。

## 2. 数据模型定义

### 2.1 科室床位统计表 `department_beds`

| 前端展示 | 数据库字段 | 类型 | 必填 | 示例 | 说明 |
|---------|-----------|------|------|------|------|
| 科室 | dept_id / name | String | 是 | `icu` / `重症医学科` | 科室编号与名称 |
| 总床 | total | Integer | 是 | `26` | 总床位数 |
| 占用 | occupied | Integer | 是 | `18` | 占用数 |
| 预留 | reserved | Integer | 是 | `2` | 预留数 |
| 空床 | free | Integer | 是 | `6` | 空床数 |

```sql
CREATE TABLE `department_beds` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `hospital_id` VARCHAR(32) NOT NULL DEFAULT '' COMMENT '医院标识，如 weiyuan',
  `dept_id` VARCHAR(32) NOT NULL COMMENT '科室编号，如 icu',
  `name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '科室名称',
  `total` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '总床位数',
  `occupied` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '占用床位数',
  `reserved` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '预留床位数',
  `free` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '空床位数',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_hospital_dept` (`hospital_id`, `dept_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='科室床位统计表';
```

### 2.2 医疗设备表 `medical_devices`

| 前端展示 | 数据库字段 | 类型 | 必填 | 说明 |
|---------|-----------|------|------|------|
| 设备 | device_id / name | String | 是 | 设备编号与名称（监护仪/输液泵） |
| 绑定床位 | bed_id / bed_label | String | 否 | 绑定床位 |
| 关联患者 | patient_id / patient_name | String | 否 | 关联患者 |
| 在线 | online | Boolean | 是 | 设备在线状态 |
| 告警 | alarm | Boolean | 是 | 参数告警 |
| 绑定时间 | bound_at | DateTime | 否 | 绑定时间 |
| 原床位 | previous_bed_id | String | 否 | 改绑前床位 |
| 解绑时间 | unbound_at | DateTime | 否 | 解绑时间 |

```sql
CREATE TABLE `medical_devices` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `device_id` VARCHAR(64) NOT NULL COMMENT '设备编号，如 MON-weiyuan-icu-1',
  `name` VARCHAR(32) NOT NULL DEFAULT '监护仪' COMMENT '设备名称',
  `bed_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '绑定床位编号',
  `bed_label` VARCHAR(64) NULL DEFAULT NULL COMMENT '绑定床位标签',
  `patient_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '关联患者编号',
  `patient_name` VARCHAR(64) NULL DEFAULT NULL COMMENT '关联患者姓名',
  `online` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '在线：0离线1在线',
  `alarm` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '告警：0无1告警',
  `bound_at` DATETIME NULL DEFAULT NULL COMMENT '绑定时间',
  `previous_bed_id` VARCHAR(64) NULL DEFAULT NULL COMMENT '改绑前床位编号',
  `unbound_at` DATETIME NULL DEFAULT NULL COMMENT '解绑时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_device_id` (`device_id`),
  KEY `idx_bed` (`bed_id`),
  KEY `idx_online_alarm` (`online`, `alarm`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='医疗设备表';
```

### 2.3 会诊会话表 `consult_sessions`

| 前端展示 | 数据库字段 | 类型 | 必填 | 示例 | 说明 |
|---------|-----------|------|------|------|------|
| 会话号 | session_id | String | 是 | `adm-2026-1001` | 会诊会话编号 |
| 模式 | mode | String | 是 | `standalone` | 运行模式 |
| 兼容120 | compatible120 | Boolean | 是 | `true` | 是否兼容 120 任务 |
| 患者姓名/性别/年龄 | patient_name / patient_gender / patient_age | - | 是 | 演示患者01 / 男 / 38 | 患者信息 |
| 主诉 | chief_complaint | String | 是 | `胸痛、出汗` | 主诉 |
| 120 任务号 | task120_id | String | 否 | `120-WY-88421` | 关联任务 |
| 医院/科室 | hospital / department | String | 是 | 威远县人民医院 / 急诊科 | 接诊科室 |
| 状态 | status | Integer | 是 | `0` | 0待接诊1会诊中2已结束 |

```sql
CREATE TABLE `consult_sessions` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `session_id` VARCHAR(64) NOT NULL COMMENT '会诊会话编号',
  `mode` VARCHAR(16) NOT NULL DEFAULT 'standalone' COMMENT '运行模式',
  `compatible120` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否兼容120任务：0否1是',
  `patient_name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '患者姓名',
  `patient_gender` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '性别：0男1女',
  `patient_age` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '年龄',
  `chief_complaint` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '主诉',
  `task120_id` VARCHAR(32) NULL DEFAULT NULL COMMENT '120 任务号',
  `hospital` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '医院',
  `department` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '科室',
  `status` TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '状态：0待接诊1会诊中2已结束',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_session_id` (`session_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='会诊会话表';
```

## 3. 接口清单

### 3.1 获取科室床位统计

| 项目 | 内容 |
|------|------|
| 接口名称 | 获取科室床位统计 |
| 请求方法 | GET |
| 请求路径 | `/api/v1/beds/by-dept` |
| 接口描述 | 按医院返回各科室总床/占用/预留/空床 |
| 前端调用时机 | `#beds` 页加载，8s 轮询 |
| 前端渲染对应 | 床位监控表格 |

**Query 参数：** `hospitalId`（String，医院标识，如 `weiyuan`）。

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "updatedAt": "2026-10-12T10:00:00+08:00",
    "hospitalId": "weiyuan",
    "departments": [
      { "id": "icu", "name": "重症医学科", "total": 26, "occupied": 18, "reserved": 2, "free": 6 },
      { "id": "emergency", "name": "急诊科", "total": 28, "occupied": 17, "reserved": 1, "free": 10 }
    ]
  }
}
```

**错误码：** 200 / 401 / 404（医院不存在）。

### 3.3 设备改绑/解绑床位

| 项目 | 内容 |
|------|------|
| 接口名称 | 设备改绑/解绑床位 |
| 请求方法 | PUT |
| 请求路径 | `/api/v1/devices/{deviceId}/binding` |
| 接口描述 | 将设备绑定到床位；`bedId` 为空表示解绑 |
| 前端调用时机 | 设备行内「改绑」下拉框变更时 |
| 前端渲染对应 | 设备绑定表格实时更新 |

**Path 参数：** `deviceId`（String）。

**Body 参数：**

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| bedId | String | 否 | 目标床位编号，空串表示解绑 | weiyuan-icu-1 |
| bedLabel | String | 否 | 床位标签 | ICU 1床 |

**请求示例：**

```http
PUT /api/v1/devices/MON-weiyuan-icu-1/binding HTTP/1.1
Authorization: Bearer {token}
Content-Type: application/json

{ "bedId": "weiyuan-icu-3", "bedLabel": "ICU 3床" }
```

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "deviceId": "MON-weiyuan-icu-1",
    "bedId": "weiyuan-icu-3",
    "bedLabel": "ICU 3床",
    "previousBedId": "weiyuan-icu-1",
    "boundAt": "2026-10-13T09:40:00+08:00"
  }
}
```

**错误码：** 200 / 400（床位不存在）/ 401 / 404（设备不存在）。

### 3.5 医生快速登记（急诊患者）

| 项目 | 内容 |
|------|------|
| 接口名称 | 急救医生快速登记 |
| 请求方法 | POST |
| 请求路径 | `/api/v1/patients` |
| 接口描述 | 急救科医生少字段快速登记患者（可保存草稿） |
| 前端调用时机 | `#register` 页点击「提交」/「存草稿」 |
| 前端渲染对应 | 医生登记表单 |

**Body 参数：**

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| name | String | 是 | 姓名 | 王秀兰 |
| gender | String | 是 | 性别 MALE/FEMALE | FEMALE |
| age | Integer | 否 | 年龄 | 45 |
| phone | String | 否 | 电话 | 13800001111 |
| chiefComplaint | String | 否 | 主诉 | 胸痛、出汗 |
| isDraft | Integer | 否 | 是否草稿（缺省 0） | 1 |

**请求示例：**

```http
POST /api/v1/patients HTTP/1.1
Authorization: Bearer {token}
Content-Type: application/json

{ "name": "王秀兰", "gender": "FEMALE", "age": 45, "phone": "13800001111", "chiefComplaint": "胸痛、出汗", "isDraft": 0 }
```

**响应示例（成功）：**

```json
{
  "code": 200,
  "message": "success",
  "data": { "patientId": "PAT-20261013-001", "isDraft": 0 }
}
```

**错误码：** 200 / 400（name 为空）/ 401。

> 说明：`POST /api/v1/patients` 复用 [`emergency_patients`] 表（见 02 §2.4），不带车辆/事件关联。

## 4. 状态与枚举值

| 字段 | code（存储） | label（显示） |
|------|-------------|--------------|
| consult.status | 0 / 1 / 2 | 待接诊 / 会诊中 / 已结束 |
| device.online | true / false | 在线 / 离线 |
| device.alarm | true / false | 参数告警 / 正常 |
| device.bedId | null / 值 | 未绑定 / 床位标签 |

## 5. 交互与边界说明

- **设备改绑**：改绑记录 `previous_bed_id` 与 `unbound_at`，解绑时清空 `patient_id`/`patient_name`，用于审计追溯。
- **床位数据**：前端目前通过「随机 ±1 抖动」模拟实时变化，正式由 ADT 事件或 WebSocket 推送更新 `occupied`/`free`。
- **会诊状态流转**：`WAITING → IN_CALL → FINISHED`；「开始会诊」将状态置为 `IN_CALL`。
- **表单校验**：姓名必填；年龄数字 0-150。

---

## 6. 前端对接注意事项

- **生命周期**：床位 8s 轮询、设备加载后本地改绑（改绑结果可即时回写后端）。
- **loading**：表格数据未返回时显示骨架；设备改绑提交按钮加 loading。
- **错误提示**：改绑失败提示「绑定失败，请重试」。
- **空数据**：无设备时显示空态；设备未绑定床位时「床位/患者」列显示「未绑定」。
