## 2. 响应与分页约定（Laravel 实装）

当前 v1 接口**未**统一包裹 `{ code, message, data }`，而是：

| 类型 | 结构 |
|------|------|
| 单条 Resource | `{ "data": { ...字段 } }` |
| 分页列表 | `{ "data": [ ... ], "links": { first, last, prev, next }, "meta": { current_page, per_page, total, ... } }` |
| 聚合/契约接口 | 裸 JSON（如 `dispatch-live`、`qc-standards/summary` 形态） |
| 校验失败 | HTTP 422，`{ "message": "...", "errors": { "field": ["..."] } }` |
| 乐观锁冲突 | HTTP 409，`{ "message": "..." }` |
| 删除成功 | HTTP 204 No Content |

**Query 分页参数**：`page`（默认 1）、`per_page`（默认 15 或 50，见各接口说明）。

时间字段：ISO 8601 字符串（Resource 层 `toIso8601String()`）。

认证：路由组当前**未**挂载 `auth:sanctum`；生产环境建议对写操作启用 Token。

#### 代码逻辑

4. **Resource 组装**：`id / org_code / org_name / org_type` 直接取库内字段；`county_name / address / lng / lat / contact_phone` ※05 未含，按本节既定返回结构输出；分页结构 `{ data, links, meta }` 见本文档 §2。

### 5.2 POST `/api/v1/transfers` — 发起转诊

**Body（JSON）**

| 字段 | 必填 | 规则 |
|------|------|------|
| from_org_id | 是 | exists:organizations |
| transfer_reason | 是 | string |
| initiator_user_id | 是 | exists:users |
| to_org_id | 否 | exists:organizations |
| event_id / patient_id | 否 | 关联急救事件/患者 |
| urgency_level | 否 | URGENCY_LOW / MEDIUM / HIGH |
| diagnosis | 否 | max:200 |
| trigger_source | 否 | max:50 |
| vehicle_id | 否 | exists:vehicles |
| driver_name / eta | 否 | |
| latest_vitals / resource_prep | 否 | array（JSON） |

**成功**：HTTP **201**，body `{ "data": TransferResource }`。  
**默认状态**：`transfer_status=TRANSFER_PENDING`，`confirm_status=CONFIRM_PENDING`（模型默认值）。

#### 代码逻辑

依据：本文档 Body 规则 + 05 `transfer` 表；校验引用落到 05 关联表（`organization` / `patient` / `sys_user`）。

1. **参数校验**（本节 Body 表；exists 校验落到 05 关联表）：`from_org_id / transfer_reason / initiator_user_id` 必填——`from_org_id / to_org_id` 引用 `organization.id`、`initiator_user_id` 引用 `sys_user.id`（实装列 ※05 未含，账号属 `sys_user`）、`patient_id` 引用 `patient.id`；`urgency_level` 限 §8.3 枚举（05 未穷举）；`event_id / diagnosis / trigger_source / vehicle_id / driver_name / eta / latest_vitals / resource_prep` ※05 未含，按实装迁移写入。
2. **落库** `transfer`（05 模块 3 §3.2）：`transfer_code` 由模型/Observer 生成（唯一）；`patient_id / from_org_id / to_org_id` 按外键写入；`urgency_level` 缺省 `URGENCY_LOW`；`transfer_status = TRANSFER_PENDING`（05 默认：待接收）、`confirm_status = CONFIRM_PENDING`（按本文档 §8.2）。
3. **返回 201**：`{ data: TransferResource }`（含嵌套 `from_org / to_org / patient`）。
