## 1. 全局约定（继承 `00-总览/README.md`，此处仅列联调必读项）

| 约定项 | 内容 |
|--------|------|
| 基础路径 | `/api/v1` |
| 认证方式 | Laravel Sanctum，`Authorization: Bearer {token}`（健康检查与登录除外） |
| 统一响应结构 | `{ "code": 200, "message": "success", "data": {} }`；`JSON_UNESCAPED_UNICODE` 输出 |
| 分页参数 | `pageNum`（从 1 起）/ `pageSize`（默认 10，最大 100）；列表响应 `data.total` + `data.list`；当前前端为全量加载 + 轮询，分页参数为可选兼容项 |
| 时间字段 | 接口返回 ISO 8601（如 `2026-10-12T14:08:00+08:00`）；库内 `DATETIME` |
| 命名规范 | 库表/字段蛇形，API 字段小驼峰，PHP 类大驼峰 |
| 数据权限 | 预留 `roleView`（`doctor` / `director`），见质控模块 §roleView |

三大模块接口共计 **37 个**：基层调度 21、医院质控 12、基层医生Dr 4。均已在既有分模块文档中逐字详述，本文档完成三模块视角的重组与核对。

### 2.4 状态流转摘要（继承全局枚举 §3.1）

- 事件/车辆 `status`：`DISPATCHING 出警中 → ON_SCENE 现场处置 → RETURNING 返院途中`，车辆另有 `STANDBY 待命`。

## 5. 覆盖核对结论

对前端 `routes/meta.ts` 全部 30 条路由逐一核对，三大模块相关 **9 条路由**均已映射接口，无遗漏、无交叉混淆：

| 前端路由 | 页面 | 对应接口 |
|----------|------|---------|
| `dispatch.html`（5 个 Tab） | 实时出警/事件/救护车/登记/监控 | #13–22（真实代码 + Mock 支撑） |
| `/dispatch` | 院前调度占位页 | #21、#23 等（按模块标签推导） |
| `/transport/:id` | 转运任务详情 | #24、#25–27 |
| `/transfers` | 转诊协同 | #62–67 |
| `/medical-quality`（+子路由） | 质控整改看板/报表/详情 | #84–88 |
| `/quality` | 质量指标 | #89–90 |
| `meeting-portal.html` 质控页 | 质控标准/SLA | #79–83 |
| `/dr` | 基层医声 | #91–94 |
| `/coordination` | 现场工作台（Dr 入口） | #91–94 复用 |

数据可信度分级：院前调度模块**有真实前端代码 + Mock 数据**支撑；质控标准/SLA 有真实 Mock；其余页面为占位脚手架，接口字段为规范设计（各详述文档均已标注）。
