# 会议导读 · 演示验收步骤（2026-10-10 录音对照）

本地先执行：

```bash
cd E:\copy\huaxi-command-center
npm install
npm run dev
```

浏览器使用终端地址（如 `http://localhost:5173`）。

- 指挥中枢首页：`/#/`（Hash 在主站 **index.html** 里）
- **120 院前四页**：`/dispatch.html#live`（**不要**写成 `/#/dispatch.html`，会显示「页面不存在」）

## 三、5 分钟冒烟清单（改完必跑）

1. `/#/` 能进首页，无长期「连接指挥中心」。
2. 120 二级菜单有 **救护车列表**，点击打开 `dispatch.html#ambulances`。
3. `dispatch.html#live` 选一条事件 → 右侧地图 + 视频占位 + 登记表单。
4. `/#/` 取消勾选「地图」→ 地图消失 → **Ctrl+F5** → 仍为取消状态。
5. `gis-command.html` 点「隐藏列表」→ 刷新 → 仍为隐藏。
6. `/#/medical-quality` 能看到环节时限相关演示块。
7. `meeting-portal.html` 可打开且链接有效。

发版前可叠加 `docs/RELEASE-CHECKLIST.md` 勾选。
