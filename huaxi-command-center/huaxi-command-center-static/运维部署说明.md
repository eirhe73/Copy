# 华西指挥中心 · 前端静态资源（运维交付）

本目录为 **生产构建产物**，无需 Node.js 即可托管。源码与二次构建见仓库 `huaxi-command-center/`（`npm install && npm run build`）。

## 1. 推荐访问入口

| 用途 | URL（示例） |
|------|-------------|
| **演示 / 业务主站** | `https://<域名>/app.html#/` |
| 登录 | `https://<域名>/index.html` → 成功后进入 `app.html` |
| 120 调度独立页 | `https://<域名>/dispatch.html` |
| GIS / 会议 / 孪生地图 | `gis-command.html`、`meeting-portal.html`、`digital-twin-map.html` |

**Hash 路由**：主 SPA 使用 `#/home`、`#/dispatch`、`#/consultations` 等，静态服务器需对所有 HTML 路径返回对应文件或 `app.html`（见 Nginx 示例）。

## 2. 部署方式

将 **本目录全部文件** 放到 Web 根目录（或子路径，子路径需保证 `/assets/` 等资源路径可访问）。

### Nginx 示例（根路径部署）

```nginx
server {
    listen 80;
    server_name your-domain.example;
    root /var/www/huaxi-command-center;
    index app.html index.html;

    location / {
        try_files $uri $uri/ /app.html;
    }

    # 可选：与前端同源反代 Laravel API，避免浏览器跨域
    # 构建时需设置 VITE_API_BASE=https://your-domain.example/api
    # 或让用户通过 ?apiOrigin= 覆盖（见下文）
    location /backend-api/ {
        proxy_pass http://127.0.0.1:7824/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 后端 API 地址

运行时默认直连（见 `assets/backend/backend-api-config.js`）：

- 默认：`http://62.234.128.72:7824/api`（可按环境改源码后重新构建，或通过下列方式覆盖）

**不改包内 JS 的临时覆盖：**

- URL 参数：`?apiOrigin=http://<后端>:7824/api`（需含 `/api`，不要带 `/v1`）
- 浏览器 localStorage：`huaxi-api-origin` = 同上

**构建时写入（推荐生产）：** 在源码目录配置 `.env` 后重新 `npm run build`：

```env
VITE_API_BASE=http://<后端主机>:7824/api
VITE_FULL_BACKEND=1
```

构建会把注入脚本写入 `app.html` 等入口（见 `<!-- INJECT_BACKEND_ENV -->`）。

## 3. 目录说明

| 路径 | 说明 |
|------|------|
| `app.html` | 主 SPA 装配页（React 预编译 bundle + enhance 脚本） |
| `assets/vendor/` | 演示用 React 大包 |
| `assets/enhance/` | 侧栏、会诊、出警等业务增强 |
| `assets/backend/` | 鉴权、API bridge、scenario 合并 |
| `assets/theme/` | 全局样式 |
| `scenario.json` | 演示数据（全后端模式下由 API 覆盖） |
| `maps/`、`models/` | 地图与 3D 资源 |

## 4. 验收清单

- [ ] `https://<域名>/app.html#/` 可打开，侧栏与首页正常
- [ ] 登录页 `index.html` 可访问（若接后端鉴权）
- [ ] 浏览器网络面板：API 请求指向预期后端，无 CORS 报错
- [ ] 静态资源 `assets/enhance/*`、`assets/backend/*` 均 200
