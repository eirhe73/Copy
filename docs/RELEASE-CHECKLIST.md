- [ ] 演示数据已标注「非临床统计 / 非实时 HIS」

## 视觉与交互（浅色指挥环境）

- [ ] 无冲击波、大面积高饱和动效

- [ ] 16:9 大屏关键控件不被裁切（GIS / 会议页 / 首页地图）
